# Chemistry & materials science

Part of [research-vault](../README.md). 53 entries, verified 2026-08-28 — free status and limits change, so check the source before you depend on it.

Beginner rating: 5/5 means a newcomer gets value in ten minutes; 1/5 means specialist tooling and patience.

## Data

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**AFLOW**](https://aflow.org) | Duke-led repository of DFT-calculated properties for millions of inorganic compounds and prototypes (4+ million entries reported in 2021), including thermodynamic, electronic and mechanical properties. *Query syntax (AFLUX) has a learning curve; like all high-throughput DFT databases, values are computed, not measured.* | Web search; AFLUX REST API for programmatic queries (no key); AFLOW prototype encyclopedia and online tools. | Free | 3/5 |
| [**CAS Common Chemistry**](https://commonchemistry.cas.org/) | Free, authoritative subset of the CAS REGISTRY covering nearly 500,000 substances: CAS numbers, names, structures and basic properties, released under CC BY-NC 4.0. *Non-commercial license (CC BY-NC 4.0); only a small fraction of the full ~200-million-substance CAS Registry, which remains a paid product (SciFinder).* | Web interface; free API after registering at cas.org/services/commonchemistry-api. | Free | 5/5 |
| [**CCDC Access Structures**](https://www.ccdc.cam.ac.uk/structures/) | Free CCDC/FIZ Karlsruhe service to search, view and download individual deposited crystal structures (CIF files) from the Cambridge Structural Database and ICSD by DOI, deposition number, name or basic search. *The full CSD (bulk database, ConQuest, Mercury advanced features, CSD Python API) requires a paid institutional license; the free route is deliberately limited in how many structures you can view and retrieve, and has no substructure/statistical search.* | Web interface; retrieve CIFs one structure at a time; depositing your own structures is also free. | Free | 4/5 |
| [**ChEMBL**](https://www.ebi.ac.uk/chembl/) | EMBL-EBI's manually curated database of drug-like bioactive molecules: ChEMBL 36 (Sept 2025) covers ~2.8 million distinct compounds, 17,803 targets and over 24 million bioactivity measurements extracted from the literature. *Data released under CC BY-SA 3.0; releases come roughly yearly, so pin the release number in any published analysis.* | Web interface; full database dumps (SQLite/PostgreSQL/MySQL) for download; Python via `pip install chembl_webresource_client`. | Free | 4/5 |
| [**ChemSpider**](https://www.chemspider.com) | Royal Society of Chemistry structure database linking over 130 million structures to properties, spectra, vendors and literature from hundreds of data sources. *Web search is free without an account; the API requires a key from the RSC developer portal and has call quotas. It is an aggregator, so verify critical values against the underlying source.* | Web interface (structure, name and property search); developer API via RSC developer portal. | Free | 5/5 |
| [**Crystallography Open Database (COD)**](https://www.crystallography.net/cod/) | Fully open collection of ~535,000 crystal structures of organic, inorganic, metal-organic compounds and minerals (Aug 2026), all downloadable as CIF with no restrictions. *Coverage overlaps with but is far smaller than the licensed CSD/ICSD; quality varies since entries come from many sources, though curation scripts are applied.* | Web search; full database mirrorable via rsync/HTTP; MySQL dumps; also queryable through the OPTIMADE API. | Free | 4/5 |
| [**JARVIS (NIST)**](https://jarvis.nist.gov) | NIST's Joint Automated Repository for Various Integrated Simulations: JARVIS-DFT holds ~40,000 3D and ~1,000 2D materials with around a million calculated properties (band gaps incl. meta-GGA, elastic, dielectric, topological), plus force-field and ML datasets. *Smaller than Materials Project/AFLOW but includes properties (spin-orbit spillage, TBmodels, 2D exfoliation energies) the others lack.* | Web apps (free sign-up); datasets downloadable via `pip install jarvis-tools` (e.g. `jarvis.db.figshare.data('dft_3d')`). | Free, email | 3/5 |
| [**MassBank (Europe)**](https://massbank.eu/MassBank/) | First public repository of reference mass spectra for small molecules: ~120,000 spectra of ~18,500 compounds from 53 contributors (2026), with a redesigned web interface launched in 2025. *Complementary siblings exist (MassBank of North America has a larger but differently curated collection); check license per record (mostly CC BY).* | Web search (spectrum, peak, substructure); complete data versioned on GitHub (MassBank/MassBank-data) with DOI-assigned releases. | Free | 4/5 |
| [**Materials Cloud**](https://www.materialscloud.org) | EPFL/MARVEL open-science platform: a moderated archive for computational materials datasets with DOIs, curated databases (e.g. MC3D/MC2D crystal structures), interactive tools, and full AiiDA provenance graphs for reproducing workflows. *Archive submissions are moderated for scope (computational materials science); browsing provenance graphs requires understanding AiiDA concepts.* | Web interface; archive records downloadable without an account; free registration to submit datasets. | Free | 3/5 |
| [**Materials Project**](https://materialsproject.org) | DFT-computed properties (formation energies, band structures, elasticity, phase diagrams) for over 150,000 inorganic materials, run by LBNL; database updated regularly (v2026.04.13 current as of mid-2026). *Computed (PBE/r2SCAN) values, not experimental — band gaps are systematically underestimated; API has rate limits but they are generous for individual use.* | Free account gives an API key; Python client `pip install mp-api` (e.g. `MPRester(API_KEY).materials.summary.search(...)`); interactive web apps; bulk data also on AWS Open Data. | Free (registration), api-key | 4/5 |
| [**NIST Chemistry WebBook**](https://webbook.nist.gov) | NIST Standard Reference Database 69: evaluated thermochemical properties, ion energetics, IR/UV-Vis/mass spectra, and thermophysical fluid properties for thousands of organic and small inorganic species. *No API or bulk export; NIST formally reserves the right to charge for access in the future, though it has been free for decades.* | Web interface (search by name, formula, CAS number, structure); no bulk download. | Free | 5/5 |
| [**nmrshiftdb2**](https://nmrshiftdb.nmr.uni-koeln.de/) | Community NMR database with ~45,000 structures and ~54,000 measured spectra (plus ~450,000 including calculated), offering free 13C/1H chemical-shift prediction and peak/structure search under an open-content license. *Prediction quality depends on how well your scaffold is represented in the community-contributed data.* | Web interface for search and prediction; open data downloads; contributions accepted after free registration. | Free | 4/5 |
| [**NOMAD**](https://nomad-lab.eu) | Open repository and archive for raw input/output files of atomistic calculations: more than 13 million entries from 60+ simulation codes (VASP, Quantum ESPRESSO, FHI-aims, GW, DMFT, MD), uploaded by hundreds of groups. *Aimed at reproducibility and data publishing rather than quick property lookup; parsing quality varies by code.* | Web browse/download without an account; free registration to upload (each upload gets a DOI); REST API and Python package `pip install nomad-lab`. | Free | 3/5 |
| [**Open Reaction Database (ORD)**](https://open-reaction-database.org) | Open schema and repository for structured organic reaction data (conditions, yields, procedures), including large USPTO-derived reaction sets and high-throughput experimentation datasets, built for machine-learning use. *Data licensed CC-BY; coverage is dominated by patent-mined and donated HTE datasets, so it is not a comprehensive reaction encyclopedia like the commercial Reaxys/SciFinder.* | Web search at client.open-reaction-database.org; raw data (protobuf) in the ord-data GitHub repo; schema tools via `pip install ord-schema`. | Free | 3/5 |
| [**OPTIMADE**](https://www.optimade.org) | A common REST API specification implemented by most major materials databases (Materials Project, AFLOW, OQMD, COD, NOMAD, JARVIS, Materials Cloud and others), letting one query format search many databases. *You still need to understand each provider's coverage and property vocabulary; the spec covers structures well, properties less uniformly.* | HTTP GET against each provider's /v1/structures endpoint with a shared filter grammar (e.g. filter=elements HAS ALL "Ti","O"); Python tools via `pip install optimade`. | Free | 2/5 |
| [**OQMD (Open Quantum Materials Database)**](https://www.oqmd.org) | Northwestern (Wolverton group) database of DFT-calculated thermodynamic and structural properties for ~1.4 million materials, strong on formation energies and ground-state phase stability. *Full-database download is tens of GB; web interface is spartan compared with Materials Project.* | Web interface; RESTful and OPTIMADE APIs; full database downloadable as a MySQL dump; Python via the `qmpy` package. | Free | 3/5 |
| [**PubChem**](https://pubchem.ncbi.nlm.nih.gov) | NIH's open chemistry database: roughly 119 million compounds and 322 million substances aggregated from over 1,000 sources (2025 update), with bioactivities, properties, spectra links, patents and literature annotations. *API politeness limits (no more than ~5 requests/second); bulk users should use the FTP dumps rather than hammering the REST API.* | Web interface; PUG-REST API (no key needed, e.g. https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/aspirin/property/CanonicalSMILES/JSON); bulk download via FTP; Python via `pip install pubchempy`. | Free | 5/5 |
| [**SDBS (Spectral Database for Organic Compounds)**](https://sdbs.db.aist.go.jp/) | AIST (Japan) database of measured spectra for ~34,000 organic compounds: 1H/13C NMR, IR, Raman, EI-MS and ESR; a standard free lookup for compound identification. *Daily access limits apply per user; some collections (e.g. Raman) are no longer updated; no bulk download.* | Web interface (search by name, formula, mass, or peak positions). | Free | 4/5 |
| [**ZINC-22**](https://cartblanche22.docking.org) | UCSF Irwin/Shoichet lab database of tens of billions of commercially available (make-on-demand) molecules in docking-ready 2D/3D formats, searchable by similarity, substructure and supplier code. *Run on academic best-effort infrastructure — large downloads can be slow; 3D conformers are precomputed with specific protonation assumptions you should check for your use case.* | CartBlanche web interface; bulk subsets via direct download, Globus, and AWS/OCI cloud mirrors. | Free | 3/5 |

## Software

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**AiiDA**](https://www.aiida.net) | Open-source (MIT) Python infrastructure for automating high-throughput atomistic calculations while recording the full provenance graph of every input, code and output; plugins exist for Quantum ESPRESSO, VASP, CP2K and many others. *Real setup cost (PostgreSQL, message broker, daemon); pays off for hundreds+ of calculations, overkill for a handful.* | `pip install aiida-core` plus a plugin (e.g. `aiida-quantumespresso`); results shareable on Materials Cloud. | Free | 2/5 |
| [**ASE (Atomic Simulation Environment)**](https://wiki.fysik.dtu.dk/ase/) | Python library (LGPL) for setting up, steering and analyzing atomistic calculations with a uniform `Atoms` object and calculator interfaces to dozens of codes (VASP, Quantum ESPRESSO, GPAW, LAMMPS, xtb, ML potentials). *ASE itself computes nothing expensive — you still need a backend DFT/forcefield code or an ML potential for real energies.* | `pip install ase`; e.g. `from ase.build import bulk; atoms = bulk('Cu')` then attach any calculator. | Free | 3/5 |
| [**Avogadro**](https://avogadro.cc) | Open-source (BSD) cross-platform molecular builder/editor used to sketch molecules in 3D, set up input files for quantum chemistry codes (ORCA, Gaussian, GAMESS) and visualize outputs and orbitals. *Avogadro 2 is the actively developed line; some legacy plugins from Avogadro 1.x are still being ported.* | Direct download of installers for Windows/macOS/Linux from avogadro.cc; no account needed. | Free | 5/5 |
| [**CP2K**](https://www.cp2k.org) | Open-source (GPL) quantum chemistry and solid-state package built around the mixed Gaussian and plane-waves method; the workhorse for ab initio molecular dynamics of condensed-phase systems (liquids, interfaces). *Input format is verbose and idiosyncratic; the online input reference and tutorials are essential.* | Source and binaries via cp2k.org; `conda install -c conda-forge cp2k`; input decks are text files run with `cp2k.x`. | Free | 2/5 |
| [**LAMMPS**](https://www.lammps.org) | Sandia's open-source (GPL-2) classical MD code, the standard for materials simulation: metals, polymers, granular systems, coarse-grained models, and now ML interatomic potentials; scales from one laptop core to the largest supercomputers. *You must supply/choose interatomic potentials yourself (see OpenKIM); script language takes time to learn — the matsci.org LAMMPS forum is the support channel.* | `conda install -c conda-forge lammps`, distro packages, or build from source; driven by text input scripts (`lmp -in in.script`). | Free | 2/5 |
| [**NWChem**](https://nwchemgit.github.io) | PNNL's open-source (ECL 2.0) computational chemistry package covering molecular HF/DFT/coupled cluster and plane-wave DFT in one code, designed to scale to large parallel machines. *Documentation is thinner than ORCA/Psi4; its niche is combined molecular+periodic capability and MPI scaling.* | `conda install -c conda-forge nwchem` or distro packages; text input files run via `nwchem input.nw`. | Free | 2/5 |
| [**Open Babel**](https://openbabel.org) | Open-source (GPL-2) toolbox that interconverts on the order of 100 chemical file formats and provides fingerprints, forcefield 3D coordinate generation and batch processing — the field's universal adapter. *Development pace has slowed; for pure Python workflows RDKit covers much of the same ground with a more active community.* | `conda install -c conda-forge openbabel` or distro packages; CLI: `obabel input.smi -O output.sdf --gen3d`; Python bindings via the `openbabel` module. | Free | 4/5 |
| [**OpenMM**](https://openmm.org) | Open-source, GPU-first molecular dynamics engine with a clean Python API and support for custom forces; extremely fast on a single consumer GPU, widely used for biomolecular and increasingly for ML-potential simulation. *Sits on the chemistry/biophysics boundary — for inorganic/hard-matter MD, LAMMPS is usually the better fit; a CUDA/OpenCL GPU makes a huge speed difference.* | `conda install -c conda-forge openmm`; Python: build a System from PDB + force field and run with a Simulation object. | Free | 3/5 |
| [**ORCA**](https://www.faccts.de/orca/) | Widely used quantum chemistry program (DFT, DLPNO-CCSD(T), multireference, spectroscopy) from the Neese group/MPI KoFo, free of charge for academic research and teaching, with over 90,000 registered academic users; current release ORCA 6.x. *Closed source; the no-cost license is worded around academic use at academic institutions — commercial use requires a paid FACCTs license, and unaffiliated researchers should read the current EULA before relying on it.* | Register a free account on the ORCA forum (orcaforum.kofo.mpg.de), then download binaries for Linux/macOS/Windows. | Free (registration), email | 3/5 |
| [**Psi4**](https://psicode.org) | Open-source (LGPL-3) quantum chemistry package: HF, DFT, MP2, coupled cluster (CCSD(T)), SAPT and more, usable as a program or as a Python module; runs fine on a laptop for small and medium molecules. *Memory/CPU hungry beyond ~50 heavy atoms with correlated methods, as with any ab initio code; excellent education resources via PsiCode and Psi4Education.* | `conda install -c conda-forge psi4`; Python: `import psi4; psi4.energy('b3lyp/cc-pvdz')` on a molecule block. | Free | 3/5 |
| [**pymatgen**](https://pymatgen.org) | The Materials Project's open-source (MIT) Python library for materials analysis: structure/symmetry manipulation, phase diagrams, Pourbaix diagrams, electronic structure analysis, and I/O for VASP, Quantum ESPRESSO, CIF and many other formats. *Tight coupling to Materials Project conventions (e.g. energy corrections) — read the docs before mixing with your own DFT numbers.* | `pip install pymatgen`; pairs with `mp-api` to pull Materials Project data straight into Structure objects. | Free | 3/5 |
| [**PySCF**](https://pyscf.org) | Apache-2.0 quantum chemistry framework written mostly in Python: molecular and periodic HF/DFT, MP2, CCSD, CASSCF, with an architecture designed for method development and hacking. *Aimed at people comfortable with electronic-structure theory; less hand-holding than Psi4 or ORCA.* | `pip install pyscf`; `from pyscf import gto, scf; scf.RHF(gto.M(atom='H 0 0 0; H 0 0 0.74', basis='sto-3g')).kernel()`. | Free | 2/5 |
| [**Quantum ESPRESSO**](https://www.quantum-espresso.org) | Open-source (GPL) suite for plane-wave pseudopotential DFT: ground states, band structures, phonons (DFPT), molecular dynamics; the most common free code for periodic solids. *Steep learning curve (pseudopotentials, k-points, cutoffs); small systems run on a laptop but production work usually needs a cluster.* | Source from quantum-espresso.org or GitLab; `conda install -c conda-forge qe`; run via `pw.x < input.in`; ASE and pymatgen can generate inputs. | Free | 2/5 |
| [**RDKit**](https://www.rdkit.org) | The de facto standard open-source cheminformatics library (BSD-3): SMILES/mol parsing, substructure search, fingerprints, descriptors, 2D depiction, 3D conformer generation, reaction handling; C++ core with Python bindings. *API is large and some behavior (sanitization, aromaticity models) surprises newcomers; the RDKit blog/Cookbook are essential reading.* | `pip install rdkit` (official wheels) or conda-forge; `from rdkit import Chem; Chem.MolFromSmiles('CCO')`. | Free | 4/5 |
| [**VESTA**](https://jp-minerals.org/vesta/en/) | Standard tool for visualizing crystal structures, electron/charge densities and crystal morphologies; reads CIF and most DFT code outputs, produces publication-quality figures. *Free of charge but not open source; distributed free for academic, scientific, educational and non-commercial users (commercial users currently also tolerated at no cost).* | Direct download for Windows/macOS/Linux from jp-minerals.org. | Free | 4/5 |
| [**xtb (GFN-xTB)**](https://github.com/grimme-lab/xtb) | Grimme group's open-source (LGPL) semiempirical quantum chemistry code implementing GFN1/GFN2-xTB and GFN-FF: geometry optimizations, conformer energies and frequencies for systems of hundreds of atoms in minutes on a laptop. *Semiempirical accuracy — great for screening, geometries and conformers, not a replacement for DFT/coupled-cluster energies.* | `conda install -c conda-forge xtb`; CLI: `xtb molecule.xyz --opt`; pairs with CREST for conformer sampling. | Free | 3/5 |

## Compute

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**ACCESS (US NSF cyberinfrastructure allocations)**](https://access-ci.org) | NSF program allocating free time on US supercomputers (Expanse, Bridges-2, Delta, Anvil and others); entry-level 'Explore' allocations need only a short abstract, and graduate students may be PIs with an advisor's letter. *US-based researchers affiliated with a US academic institution, nonprofit or FFRDC only — genuinely unaffiliated researchers are not eligible; larger tiers require progressively more justification.* | Create an ACCESS account, submit an Explore request (a few paragraphs) at allocations.access-ci.org; awards are exchanged for credits on specific machines. | Free, application | 2/5 |
| [**ChemCompute**](https://chemcompute.org) | Free web gateway (NSF-supported) that runs GAMESS quantum chemistry, TINKER and NAMD molecular dynamics jobs on real HPC resources (Expanse, Bridges-2) with both guided student modes and a raw input-file researcher mode. *Built for undergraduate teaching and research; fair-use queueing rather than guaranteed allocations — heavy production users should seek proper allocations (e.g. ACCESS).* | Register free at chemcompute.org (academic email recommended), submit jobs via web forms or uploaded input files. | Free (registration), email | 5/5 |
| [**nanoHUB**](https://nanohub.org) | NSF-funded Purdue platform where hundreds of nanotechnology and materials simulation tools (including DFT and semiconductor device tools) run in the cloud through your browser, alongside 1,000+ courses and learning modules. *Per-session compute is modest — good for education, prototyping and small research jobs, not production HPC campaigns.* | Free account, then launch tools directly in the browser — no local install. | Free (registration), email | 4/5 |

## Learning

| [**Deep Learning for Molecules and Materials (dmol.pub)**](https://dmol.pub) | Andrew White's free online book on machine learning for chemistry and materials: graph neural networks, equivariances, generative models, with every chapter as runnable Jupyter code. *Assumes working Python and some ML background; the fast-moving field means some chapters lag the latest architectures.* | Read in the browser; run chapters via the included Colab/Jupyter links; source on GitHub. | Free | 4/5 |
