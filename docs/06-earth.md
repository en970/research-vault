# Earth, climate & environmental science

Part of [research-vault](../README.md). 55 entries, verified 2026-08-28 — free status and limits change, so check the source before you depend on it.

Beginner rating: 5/5 means a newcomer gets value in ten minutes; 1/5 means specialist tooling and patience.

## Data

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**Argo**](https://argo.ucsd.edu/) | Global array of ~4,000 autonomous floats profiling temperature and salinity in the upper 2,000 m (Deep Argo to 6,000 m; BGC-Argo adds oxygen, pH, nitrate and more). Over 3 million profiles collected since 2000 (3-millionth in July 2024), about 100,000 per year, all free. *Use delayed-mode (quality-controlled) data for science where available; real-time data carry only automated QC. File structure is fiddly - argopy exists precisely to hide it.* | `pip install argopy` for a pandas/xarray interface with regional/float/profile fetchers; raw netCDF from the Ifremer and US GODAE GDACs via HTTPS/S3; several ERDDAP servers also serve Argo. | Free | 3/5 |
| [**CHELSA**](https://chelsa-climate.org/) | Downscaled global climate dataset at 30 arc-seconds (~1 km) built from ERA-Interim/ERA5 with orographic corrections; monthly climatologies (1981-2010), bioclim variables, time series and CMIP downscaled scenarios. Often outperforms station-interpolated products in mountains and data-sparse regions. *Files are large (global 1 km layers); download per-variable and clip early. Cite the specific version (V2.1 is current).* | Direct download of GeoTIFFs from the site's download section (S3-hosted; wget file lists provided); no registration. | Free | 4/5 |
| [**CMIP6 via ESGF**](https://esgf-node.llnl.gov/) | The Earth System Grid Federation distributes the complete CMIP6 archive (and growing CMIP7 holdings): output from dozens of modelling centres for historical, scenario (SSP) and idealised experiments. *Most CMIP6 data are CC-licensed and need no login; a few older restricted datasets require an ESGF account. Volumes are huge - subset by variable/experiment/model before downloading, or work from the cloud Zarr stores.* | Search with the Metagrid interface at esgf-node.llnl.gov (mirrors at DKRZ, CEDA, IPSL), download via generated wget scripts or Globus; for laptop-scale work use the analysis-ready Zarr mirrors on Google Cloud/AWS through `pip install intake-esm` and the Pangeo CMIP6 catalog. | Free | 2/5 |
| [**Copernicus Climate Data Store (ERA5)**](https://cds.climate.copernicus.eu/) | Home of ERA5, the ECMWF global reanalysis: hourly fields from 1940 to near-present at 0.25 deg (ERA5-Land at 0.1 deg from 1950), plus seasonal forecasts, satellite climate records and sectoral climate indicators. *Requests are queued; large ERA5 pulls can wait hours. Learn to request only the variables/levels/area you need. For quick point extractions of ERA5, the Open-Meteo historical API is much faster.* | Register free at cds.climate.copernicus.eu, put the API key in ~/.cdsapirc, then `pip install cdsapi` and submit retrieval requests in Python; a web download form exists for small requests. | Free (registration), api-key | 3/5 |
| [**Copernicus Data Space Ecosystem**](https://dataspace.copernicus.eu/) | The official access point for the EU Copernicus Sentinel missions: Sentinel-1 SAR, Sentinel-2 optical (10 m), Sentinel-3 and Sentinel-5P atmospheric data, with the full mission archives online. Replaces the old Copernicus Open Access Hub (SciHub), which was retired in 2023. *Per-account service quotas (concurrent connections, monthly transfer) apply to the free tier but are ample for individual research. Processing on the platform uses the separate openEO credit system (see the openEO entry).* | Free account at dataspace.copernicus.eu; browse in Copernicus Browser, or script against the STAC and OData APIs at catalogue.dataspace.copernicus.eu; S3-compatible access is also offered. | Free (registration), email | 3/5 |
| [**Copernicus Marine Service**](https://marine.copernicus.eu/) | Free EU service distributing global and regional ocean analyses, forecasts, reanalyses and satellite ocean products (temperature, salinity, currents, sea level, biogeochemistry, sea ice). *Product catalogue is large and naming is bureaucratic; use the web catalogue to find the product ID before scripting.* | Free registration at data.marine.copernicus.eu, then `pip install copernicusmarine`; the CLI/Python toolbox (`copernicusmarine subset`) downloads regional and temporal cuts without fetching whole files. | Free (registration), email | 3/5 |
| [**EarthScope (SAGE/IRIS) Data Services**](https://www.earthscope.org/data/) | The NSF national archive for seismological data (formerly the IRIS DMC): decades of continuous waveforms and station metadata from thousands of seismometers worldwide, served through standard FDSN web services. *Mid-migration to the cloud in 2026: fdsnws-dataselect and fdsnws-station have moved hosts, and the irisws-timeseries processing service is retired as of 26 Aug 2026 (do processing client-side with ObsPy instead). A small subset of networks embargo recent data.* | FDSN web services now at service.earthscope.org (migrated from service.iris.edu); in Python `pip install obspy` then Client('IRIS').get_waveforms(net, sta, loc, chan, t1, t2) - ObsPy follows the redirects. | Free | 2/5 |
| [**EM-DAT**](https://public.emdat.be/) | The international disaster database maintained by CRED (UCLouvain): standardised records of natural and technological disasters worldwide since 1900, with deaths, people affected and economic losses per event. *Commercial use requires a paid subscription. Entry threshold (10+ deaths, 100+ affected, emergency declaration or international appeal) and reporting practices changed over time - be careful with long trend analyses; pre-2000 records are flagged as lower quality.* | Register free at public.emdat.be (non-commercial use), then download the full database as .xlsx from the Access Data tab. | Free (registration), email | 4/5 |
| [**GBIF**](https://www.gbif.org/) | Global Biodiversity Information Facility: 3.1+ billion species occurrence records from over 2,500 publishing institutions, integrated with a common taxonomy and standard (Darwin Core). *Occurrence data carry strong spatial and taxonomic sampling biases and variable coordinate precision - filter by issues/flags before analysis. Cite the download DOI, not 'GBIF' generically.* | Search API at api.gbif.org/v1 needs no key; citable bulk downloads (with DOI) require a free gbif.org account; `pip install pygbif` or R package rgbif; full snapshots on AWS/Azure open data. | Free (registration), email | 4/5 |
| [**GEBCO**](https://www.gebco.net/) | The standard freely available global ocean depth/land elevation grid at 15 arc-second spacing. The GEBCO_2026 grid (published 23 April 2026) incorporates Seabed 2030 contributions; 28.7% of the ocean floor is now mapped to modern standards. *Away from surveyed tracks, depths are interpolated from satellite altimetry - fine for context maps, not for navigation or fine-scale seafloor work. A type-identifier grid tells you which cells are real measurements.* | Direct download of the global netCDF or user-defined tiles (netCDF/GeoTIFF/ASCII) at download.gebco.net; also served via OPeNDAP. | Free | 4/5 |
| [**Global Forest Watch**](https://www.globalforestwatch.org/) | WRI platform serving the Hansen/UMD global tree-cover-loss dataset (30 m, annual from 2001, updated yearly) plus near-real-time deforestation and fire alerts (GLAD, RADD) and carbon layers. *'Tree cover loss' is not the same as deforestation (includes harvest, fire, plantations); the makers themselves warn against naive year-over-year trend comparisons across sensor-era changes.* | Interactive dashboards at globalforestwatch.org (no login); bulk data via the Open Data Portal (data.globalforestwatch.org) and the Data API (data-api.globalforestwatch.org); analysis in a country/AOI is point-and-click. | Free | 5/5 |
| [**NASA Earthdata**](https://www.earthdata.nasa.gov/) | Single free login for NASA's petabyte-scale Earth observation holdings across 12 thematic DAACs: MODIS, VIIRS, ICESat-2, GRACE, GPM precipitation, SMAP soil moisture, NISAR and much more. *Data are increasingly served from AWS (Earthdata Cloud); direct in-region S3 access is free only from us-west-2, but HTTPS download works from anywhere.* | Create a free Earthdata Login at urs.earthdata.nasa.gov; then `pip install earthaccess` and use earthaccess.search_data()/.download() (handles authentication), or search interactively at search.earthdata.nasa.gov. | Free (registration), email | 3/5 |
| [**NASA FIRMS**](https://firms.modaps.eosdis.nasa.gov/) | Fire Information for Resource Management System: near-real-time active-fire detections from VIIRS (375 m) and MODIS (1 km), typically available within ~3 hours of overpass, plus the full detection archive back to 2000 (MODIS). *Detections are thermal anomalies, not confirmed fires (gas flares, volcanoes and sun glint appear); cloud cover causes misses. API keys have transaction limits per 10-minute window.* | Interactive fire map needs no login; for data, request a free MAP_KEY (instant, email) and pull CSV/JSON via the area API, or order archive downloads. | Free, api-key | 4/5 |
| [**NASA POWER**](https://power.larc.nasa.gov/) | Analysis-ready daily/hourly/monthly solar radiation and meteorology (from MERRA-2 and CERES) for any point on the globe, from the 1980s to near-present. Designed for agronomy, renewable energy and building science. *Gridded at coarse reanalysis resolution (~0.5 deg); fine for time series at a site, not for spatial detail.* | REST API at power.larc.nasa.gov/api with no key: point, regional and climatology endpoints returning JSON/CSV; also a web Data Access Viewer for interactive download. | Free | 5/5 |
| [**Natural Earth**](https://www.naturalearthdata.com/) | Public-domain vector and raster basemap data at 1:10m, 1:50m and 1:110m scales - coastlines, countries, rivers, lakes, populated places - built for making clean small-scale maps. *Public domain, so no attribution legally required (though appreciated). Boundaries follow de facto control; check the disputed-areas layers if that matters for your maps.* | Direct download (shapefiles/GeoPackage/rasters) at naturalearthdata.com; also fetchable from cartopy and geopandas helper functions. | Free | 5/5 |
| [**NOAA NCEI / Climate Data Online (GHCN)**](https://www.ncei.noaa.gov/cdo-web/) | World's largest archive of land-station climate records: GHCN-daily covers 100,000+ stations in 180 countries, with monthly (GHCNm) and hourly (GHCNh, replacing ISD) companions. *Token needed only for the CDO API, not for bulk file download. Some derived NOAA products were retired in 2025 amid budget cuts (e.g. the Billion-Dollar Disasters product); the core station archives remain, but check product pages for status.* | Web search/cart at ncei.noaa.gov/cdo-web; REST API v2 with a free token (limits: 5 requests/s, 10,000 requests/day); raw GHCN flat files are direct download and also mirrored on AWS Open Data (s3://noaa-ghcn-pds). | Free, api-key | 4/5 |
| [**Open-Meteo**](https://open-meteo.com/) | Open-source weather API serving forecasts from multiple national models plus a gap-free historical archive built on ERA5 (0.25 deg, from 1940) and ERA5-Land (0.1 deg, from 1950). Data are redistributed under CC-BY 4.0. *Free for non-commercial use up to roughly 10,000 calls/day; commercial or heavier use requires a paid plan. Far quicker than the Copernicus CDS for point-based ERA5 extraction.* | Plain HTTPS, no key, e.g. https://archive-api.open-meteo.com/v1/archive?latitude=..&longitude=..&start_date=..&daily=temperature_2m_max; `pip install openmeteo-requests` for a typed client. | Free | 5/5 |
| [**OpenAerialMap**](https://openaerialmap.org/) | Open catalogue of openly licensed (CC-BY 4.0) aerial and drone imagery, heavily used after disasters via the Humanitarian OpenStreetMap community; imagery is served as cloud-optimised GeoTIFFs and web tiles. *Coverage is patchy by design - dense where mapping campaigns or disasters occurred, absent elsewhere. Check acquisition dates carefully.* | Browse and download at map.openaerialmap.org; programmatic search via the API at api.openaerialmap.org; anyone can also upload imagery. | Free | 4/5 |
| [**OpenStreetMap (Geofabrik & Overpass)**](https://www.openstreetmap.org/) | Crowd-sourced global geodatabase of roads, buildings, land use, waterways and POIs - the de facto free base vector layer for environmental and hazards research. *ODbL licence: derived databases must be shared under compatible terms - fine for research, but read it before mixing with proprietary data. Public Overpass instances enforce fair-use limits; heavy jobs should use Geofabrik extracts locally.* | Country/region extracts updated daily at download.geofabrik.de (no registration); ad-hoc spatial queries via the Overpass API (try overpass-turbo.eu); `pip install osmnx` for street networks and features in Python. | Free | 4/5 |
| [**OpenTopography**](https://opentopography.org/) | NSF-funded portal for high-resolution topography: hundreds of airborne/terrestrial lidar point clouds plus on-demand access to global DEMs (SRTM, Copernicus GLO-30/90, NASADEM, ArcticDEM, REMA) with server-side processing. *Global-DEM API is rate-limited: 200 calls/day with an academic (.edu-verified) key, 50/day otherwise; ~4x4 degree area cap per request. Higher limits need a paid OpenTopography Plus subscription. Lidar holdings are US-heavy.* | Free account generates an API key instantly; REST endpoint /API/globaldem returns clipped DEMs; web portal for lidar jobs; the QGIS 'OpenTopography DEM Downloader' plugin wraps the API. | Free tier, api-key | 4/5 |
| [**PANGAEA**](https://www.pangaea.de/) | Long-running open-access publisher and archive for georeferenced earth and environmental science data (hosted by AWI/MARUM, Germany); every dataset is curated, DOI-minted and citable. *Also a realistic place to publish your own data at no cost (curation is free), which satisfies journal data-availability requirements. A minority of datasets are under temporary moratorium.* | Web search at pangaea.de with direct download (mostly tab-delimited text); `pip install pangaeapy` for scripted retrieval by DOI. | Free | 4/5 |
| [**SoilGrids**](https://soilgrids.org/) | ISRIC's machine-learning global soil maps at 250 m: pH, organic carbon, texture fractions, bulk density, nitrogen and more at six standard depths, each with uncertainty layers. *Global model predictions, not survey maps - uncertainty is substantial in under-sampled regions; always propagate the provided uncertainty layers rather than treating values as ground truth.* | Web viewer at soilgrids.org; point queries via the REST API at rest.isric.org; full maps as cloud-optimised GeoTIFFs/VRTs at files.isric.org or via WCS at maps.isric.org. | Free | 3/5 |
| [**USGS EarthExplorer**](https://earthexplorer.usgs.gov/) | Download portal for the full Landsat archive (1972-present, 30 m multispectral since 1982) plus declassified spy imagery, aerial photos and other USGS collections. All Landsat data have been free since 2008. *M2M API access requires a separate (free) approval step. Landsat Collection 2 is also mirrored on AWS and Google Cloud as COGs, which is often easier for scripted work.* | Web interface at earthexplorer.usgs.gov (free account required to download); bulk/scripted ordering via the Machine-to-Machine (M2M) API after requesting access approval from your profile. | Free (registration), email | 3/5 |
| [**USGS Earthquake Hazards Program (ComCat)**](https://earthquake.usgs.gov/) | Authoritative global earthquake catalogue (ANSS ComCat) with locations, magnitudes, moment tensors, ShakeMap and PAGER products, plus real-time GeoJSON feeds updated every minute. *Query results capped (20,000 events per request) - page by time window for bulk pulls. Global completeness is roughly M4.5+; use regional catalogues for smaller events outside the US.* | Real-time GeoJSON feeds at earthquake.usgs.gov/earthquakes/feed; historical queries via the fdsnws-event API (also reachable from ObsPy's FDSN client); interactive search on the website. | Free | 5/5 |
| [**WorldClim**](https://www.worldclim.org/) | Standard global climate surfaces for ecology and species distribution modelling: monthly temperature/precipitation climatologies for 1970-2000 at four resolutions down to 30 arc-seconds (~1 km), the 19 'bioclim' variables, and CMIP6-based downscaled future projections. *Baseline period is 1970-2000 - already far from current climate; interpolation quality degrades where stations are sparse (tropics, mountains). Compare with CHELSA before committing.* | Direct download of GeoTIFF zips at worldclim.org (no registration); read with terra (R) or rioxarray (Python). | Free | 5/5 |

## Software

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**Climate Data Operators (CDO)**](https://code.mpimet.mpg.de/projects/cdo) | Max Planck Institute's command-line toolkit with hundreds of chainable operators for netCDF/GRIB climate files: regridding, temporal statistics, ensemble math, field selection - the workhorse of CMIP-style processing. *Terse syntax and cryptic errors, but far faster than naive Python loops for bulk file processing; NCO is the complementary tool for attribute/metadata surgery.* | `conda install -c conda-forge cdo`; operators chain right-to-left, e.g. `cdo -yearmean -selname,tas input.nc out.nc`. | Free | 2/5 |
| [**GDAL/OGR**](https://gdal.org/) | The translator library underneath nearly all open geospatial software, reading and writing hundreds of raster and vector formats; its CLI tools do reprojection, mosaicking, clipping and format conversion at scale. *Prefer conda-forge or OS packages over pip for a working build with all drivers. Learning the CLI pays off more than the raw Python bindings (or use rasterio/rioxarray on top).* | `conda install -c conda-forge gdal` (or OS packages); command-line tools gdal_translate, gdalwarp, ogr2ogr, gdalbuildvrt plus Python bindings. | Free | 3/5 |
| [**GeoPandas**](https://geopandas.org/) | Pandas extended with geometry columns: file I/O for all OGR formats, spatial joins, overlays, projections and quick plotting - the standard Python entry point for vector geodata. *Memory-bound for very large layers; pair with pyogrio (default engine in recent versions) and spatial filters at read time.* | `pip install geopandas`; gpd.read_file() for any vector format, .explore() renders an interactive web map in one line. | Free | 4/5 |
| [**GRASS GIS**](https://grass.osgeo.org/) | Veteran open-source GIS (development since 1982) with 400+ analysis modules, particularly strong in hydrology, terrain analysis and large-raster processing; scriptable from Python and callable from QGIS. *The location/mapset data model confuses newcomers; if you only need one watershed delineation, the QGIS-GRASS integration is the gentler route.* | Download at grass.osgeo.org (or OSGeo4W/conda); use standalone, through the QGIS processing toolbox, or via grass.script / grass.jupyter in Python. | Free | 2/5 |
| [**Leafmap**](https://leafmap.org/) | Python package for interactive geospatial visualisation and analysis in Jupyter with minimal code: drag-and-drop layers, basemap gallery, COG/STAC support, and split-map comparisons; sibling of geemap (same author) for Earth Engine. *Visualisation-first: for heavy processing you still drop down to GDAL/xarray, but for exploring data it is the fastest on-ramp in the Python ecosystem.* | `pip install leafmap`; m = leafmap.Map(); m.add_raster('dem.tif'); works with ipyleaflet, folium and MapLibre backends. | Free | 4/5 |
| [**ObsPy**](https://www.obspy.org/) | The standard Python framework for seismology: reads all common waveform formats (miniSEED, SAC), speaks FDSN web services for data download, and provides filtering, instrument-response removal, triggering and plotting. *Its tutorial gallery doubles as a seismic data processing course. Update to a recent version so FDSN endpoints (EarthScope migration) resolve correctly.* | `pip install obspy`; read('file.mseed') for local data, Client('IRIS').get_waveforms(...) for remote archives. | Free | 3/5 |
| [**PyGMT**](https://www.pygmt.org/) | Python interface to the Generic Mapping Tools (GMT 6), the geoscience community's standard for publication-quality maps, gridding and geodesy-aware plotting; ships with easy access to remote datasets like Earth relief. *Conda installation strongly recommended (needs the GMT C library). Classic GMT shell syntax remains available if you inherit old scripts.* | `conda install -c conda-forge pygmt`; fig = pygmt.Figure(); fig.coast(...); fig.grdimage('@earth_relief_01m', region=[...]). | Free | 3/5 |
| [**QGIS**](https://qgis.org/) | The leading open-source desktop GIS: visualisation, editing, analysis and cartography for raster and vector data, with a large plugin ecosystem and Python (PyQGIS) scripting. *Use the Long Term Release (LTR) for stability. Runs fine on modest laptops for most tasks.* | Installers for Windows/macOS/Linux at qgis.org; install plugins (e.g. OpenTopography downloader, QuickMapServices) from the built-in manager. | Free | 5/5 |
| [**xarray (+ rioxarray)**](https://xarray.dev/) | The core Python library for gridded earth data: labelled multi-dimensional arrays with named coordinates, reading netCDF, Zarr and GRIB (via cfgrib), and scaling past RAM with Dask. rioxarray adds CRS-aware raster I/O on top. *The whole modern climate/EO Python stack (Pangeo) is built around it - worth learning properly via Project Pythia before touching big datasets.* | `pip install xarray rioxarray dask`; xr.open_dataset('era5.nc') then .sel(time=..., latitude=...) for label-based subsetting. | Free | 3/5 |
