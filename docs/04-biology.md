# Biology & life sciences

Part of [research-vault](../README.md). 54 entries, verified 2026-08-28 — free status and limits change, so check the source before you depend on it.

Beginner rating: 5/5 means a newcomer gets value in ten minutes; 1/5 means specialist tooling and patience.

## Data

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**Alliance of Genome Resources**](https://www.alliancegenome.org/) | Unified portal over the major model-organism knowledgebases — FlyBase (Drosophila), WormBase (C. elegans), ZFIN (zebrafish), MGI (mouse), RGD (rat), SGD (yeast) — plus the Gene Ontology, with harmonized gene, allele, disease and expression pages. *For organism-specific depth (stocks, community nomenclature, curation detail) the individual databases are still worth visiting directly.* | Web search across all member organisms; bulk downloads page; REST APIs; the individual member databases remain available and free. | Free | 4/5 |
| [**AlphaFold Protein Structure Database**](https://alphafold.ebi.ac.uk/) | EMBL-EBI/Google DeepMind database of AlphaFold2-predicted structures covering over 214 million protein sequences — structure coverage for most of UniProt. Each entry includes per-residue confidence (pLDDT) and predicted aligned error. *Predictions are CC BY 4.0. Confidence varies a lot by region — always check pLDDT before building on a model. For sequences not in the database, use ColabFold to predict your own.* | Search by protein name or UniProt accession on the web; per-entry PDB/mmCIF download; REST API (alphafold.ebi.ac.uk/api); full-proteome tarballs and bulk mirrors on Google Cloud Storage. | Free | 5/5 |
| [**BOLD Systems**](https://boldsystems.org/) | The Barcode of Life Data System holds over 20.7 million public DNA barcode records representing about 1.6 million species (2026), with specimen metadata, images and the standard reference library for barcode-based species identification. *Uploading and managing your own projects requires a free account; the identification engine and public records need none.* | Public data portal for search and bulk download; sequence identification engine on the web; data packages for offline use; API for scripted queries. | Free | 4/5 |
| [**CZ CELLxGENE Discover**](https://cellxgene.cziscience.com/) | Chan Zuckerberg Initiative portal aggregating over 90 million unique cells from hundreds of standardized single-cell datasets (human and mouse), including much of the Human Cell Atlas. The Census API exposes the whole corpus for programmatic slicing. *Datasets are standardized to a common schema (CC licenses per dataset). Whole-corpus queries stream from the cloud, so a laptop with decent bandwidth suffices for surprisingly large analyses.* | Interactive web explorer per dataset; `pip install cellxgene-census` to query the full corpus and pull slices as AnnData (Python) or Seurat/SingleCellExperiment (R) objects. | Free | 4/5 |
| [**eBird**](https://ebird.org/) | Cornell Lab of Ornithology platform that passed 2 billion bird observations in June 2025, drawn from 150 million checklists by 1.1 million contributors in 253 countries. The associated Macaulay Library holds millions of audio recordings, photos and videos. *The full EBD is hundreds of GB — use the custom download filters or `auk` to subset. Macaulay Library media downloads require a separate request; media are free for research but not automatically openly licensed.* | Request the eBird Basic Dataset (EBD) at ebird.org/data/download with a free account and a short data-request form (approval typically within 7 days); analyze with the R package `auk`; a public API serves recent observations. | Free, application | 4/5 |
| [**Ensembl**](https://www.ensembl.org/) | EMBL-EBI's genome browser and annotation system covering hundreds of vertebrate genomes, with sister site Ensembl Genomes for plants, fungi, protists, bacteria and invertebrates. Provides consistent gene models, variation, comparative genomics and regulatory annotation. *REST API is rate-limited (headers tell you your allowance); very large jobs should use the FTP dumps or BioMart instead of the API.* | Web browser; REST API at rest.ensembl.org (JSON); BioMart for bulk custom tables; full releases on ftp.ensembl.org; Perl/Python APIs. | Free | 4/5 |
| [**European Nucleotide Archive (ENA)**](https://www.ebi.ac.uk/ena/browser/home) | EMBL-EBI's INSDC node, holding the same globally synchronized sequence data as GenBank/DDBJ plus raw reads. Often the fastest route to FASTQ files because it serves them as direct HTTP/FTP downloads without special tooling. *For SRA accessions, checking ENA first frequently avoids the sra-tools conversion step entirely.* | Web browser; ENA Portal API (https://www.ebi.ac.uk/ena/portal/api/) for scripted queries; direct FASTQ URLs per run accession; enaBrowserTools scripts on GitHub. | Free | 3/5 |
| [**GBIF**](https://www.gbif.org/) | The Global Biodiversity Information Facility indexes roughly 3 billion species occurrence records from over 2,400 publishing institutions — museum specimens, surveys, and citizen-science platforms — under open licenses. *Record quality varies by source — filter on coordinate issues and basis-of-record. Citing the download DOI is expected practice.* | Web download (free account required; each download gets a citable DOI); REST API at api.gbif.org; R package `rgbif` and Python `pygbif`; full monthly snapshots on AWS Open Data. | Free, email | 4/5 |
| [**GenBank (NCBI)**](https://www.ncbi.nlm.nih.gov/genbank/) | The US national archive of all publicly available nucleotide sequences, synchronized daily with ENA (Europe) and DDBJ (Japan) as part of the INSDC. Also the gateway to RefSeq, NCBI's curated non-redundant set of reference sequences. *E-utilities are rate-limited to 3 requests/second without a key; a free NCBI API key raises this to 10/second. No login needed for search or download.* | Web search at ncbi.nlm.nih.gov/nuccore; programmatic access via E-utilities REST API (eutils.ncbi.nlm.nih.gov) or Bio.Entrez in Biopython (`pip install biopython`); bulk data and RefSeq via the `datasets` CLI tool and FTP. | Free | 4/5 |
| [**Gene Expression Omnibus (GEO)**](https://www.ncbi.nlm.nih.gov/geo/) | NCBI's public repository for microarray and sequencing-based functional genomics; it already held over 100,000 studies comprising millions of samples by 2018 and has roughly doubled every two years since. Most journals require deposition here, so nearly every published expression dataset is retrievable. *Processed data quality and formats vary by submitter; raw reads for sequencing studies usually live in SRA under a linked accession.* | Web search by accession (GSExxxxx); in R, `BiocManager::install("GEOquery")` then `getGEO("GSE...")`; bulk supplementary files via FTP. | Free | 3/5 |
| [**gnomAD**](https://gnomad.broadinstitute.org/) | The Genome Aggregation Database v4.1 aggregates variant frequencies from 807,162 individuals (730,947 exomes + 76,215 genomes), the standard reference for allele frequencies in human genetics and variant interpretation. *Aggregate frequency data only — no individual-level genotypes. Full downloads are multi-terabyte; the browser or per-gene queries serve most use cases.* | Browser at gnomad.broadinstitute.org (no login); full VCF and Hail Table downloads from free public buckets on AWS, Azure and Google Cloud. | Free | 4/5 |
| [**Human Protein Atlas**](https://www.proteinatlas.org/) | Swedish open-access atlas mapping the human proteome across tissues, cells and organs using antibody-based imaging, transcriptomics and mass spectrometry; version 24 adds multiplex tissue profiling. One of the most visited biological databases. *Data is released under CC BY-SA, so derivative works must share alike — check before embedding in differently licensed resources.* | Web search by gene/protein; bulk downloadable TSV/XML/JSON; previous versions archived (e.g. v22.proteinatlas.org) for reproducibility. | Free | 5/5 |
| [**IGSR / 1000 Genomes Project**](https://www.internationalgenome.org/) | The International Genome Sample Resource hosts the fully open 1000 Genomes data: 2,504 individuals from 26 populations (phase 3), plus the expanded 3,202-sample high-coverage resequencing. One of the few human WGS datasets with no access application at all. *Samples carry broad consent for open release, which is why no application is needed — unlike nearly every other human cohort. Files are large; per-chromosome VCFs keep things laptop-friendly.* | Direct FTP/HTTP download of alignments and VCFs; data portal for browsing samples and populations; also mirrored on AWS Open Data. | Free | 2/5 |
| [**iNaturalist**](https://www.inaturalist.org/) | Community platform that passed 300 million species observations in spring 2026, each with photos/audio and community identification. Research-grade records flow automatically into GBIF, making it one of the largest biodiversity data sources. *Observers choose licenses per record; filter for CC-licensed records if you need reuse rights. Identifications are community consensus, not expert vouchers.* | Browse and export from the web; REST API at api.inaturalist.org; bulk research-grade data best pulled via GBIF; contributing observations needs a free account. | Free | 5/5 |
| [**Movebank**](https://www.movebank.org/) | Free global database of animal movement hosted by the Max Planck Institute of Animal Behavior: 10.9 billion animal locations and 9 billion other sensor measurements across more than 10,000 studies as of May 2026. *Data owners control sharing — a substantial fraction of studies require permission or accepting license terms before download.* | Web map and study browser; R package `move2` for programmatic download; many studies are fully public, others on request from the data owner; curated open datasets published via the Movebank Data Repository with DOIs. | Free, email | 3/5 |
| [**RCSB Protein Data Bank**](https://www.rcsb.org/) | US portal to the worldwide PDB archive of experimentally determined biomolecular structures: 259,129 experimental structures plus over 1 million computed structure models searchable alongside them (August 2026). *PDB data carries no usage restrictions (CC0). Same archive is served by PDBe (Europe) and PDBj (Japan) with different tooling.* | Web search and 3D viewer (Mol*); structure files from files.rcsb.org; Search and Data REST/GraphQL APIs; Python package `rcsb-api`. | Free | 5/5 |
| [**Sequence Read Archive (SRA)**](https://www.ncbi.nlm.nih.gov/sra) | The world's largest repository of raw high-throughput sequencing data; public holdings exceeded 25 petabase pairs across ~15 million runs by late 2021 and have kept growing. All public runs are mirrored to free open-data buckets on AWS and Google Cloud. *Controlled-access human data (e.g. dbGaP studies) requires a formal data-access application; everything labeled public is unrestricted. Large downloads are bandwidth-bound, not policy-bound.* | `conda install -c bioconda sra-tools`, then `prefetch SRR...` and `fasterq-dump SRR...`; runs are also directly downloadable from the AWS Open Data mirror without any NCBI tooling. | Free | 3/5 |
| [**UCSC Genome Browser**](https://genome.ucsc.edu/) | The original interactive genome browser (since 2000), hosting assemblies and hundreds of annotation tracks for human, mouse and many other species, plus tools such as BLAT, liftOver and the Table Browser for bulk track export. *The website is free for everyone; a few downloadable command-line binaries (e.g. BLAT, liftOver executables) require a paid license for commercial use only.* | Web interface; Table Browser for downloads; REST API at api.genome.ucsc.edu; full data mirrors via rsync; custom track hubs let you visualize your own data free. | Free | 4/5 |
| [**UniProt**](https://www.uniprot.org/) | The central protein knowledgebase: UniProtKB/Swiss-Prot contains 575,503 expert-curated entries (release 2026_02) and UniProtKB/TrEMBL adds hundreds of millions of automatically annotated sequences. Cross-linked to structures, pathways, and literature. *Data is CC BY 4.0, so reuse requires only attribution.* | Web search; REST API at rest.uniprot.org (supports pagination and ID mapping); bulk FTP downloads of full releases. | Free | 5/5 |

## Software

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**Bioconductor**](https://bioconductor.org/) | The standard R ecosystem for high-throughput biology: release 3.23 (April 2026) ships 2,418 software packages plus annotation and experiment data packages, covering RNA-seq (DESeq2, edgeR), single-cell, methylation, proteomics and more. *Two releases per year tied to R versions; keep R current or pin a Bioconductor release for reproducibility.* | In R: `install.packages("BiocManager")` then `BiocManager::install("DESeq2")` (or any package); extensive per-package vignettes. | Free | 3/5 |
| [**Biopython**](https://biopython.org/) | The long-standing open-source Python library for computational biology: sequence parsing (FASTA/GenBank), NCBI Entrez access, alignments, phylogenetics, and PDB structure handling. *Set Entrez.email (and ideally a free NCBI API key) when using Bio.Entrez to respect NCBI rate limits.* | `pip install biopython`; e.g. `from Bio import SeqIO` to parse sequence files, `Bio.Entrez` to query NCBI. | Free | 4/5 |
| [**CellProfiler**](https://cellprofiler.org/) | Broad Institute's free software for building automated image-analysis pipelines without programming — the standard tool for quantifying cells across thousands of microscopy images (counts, morphology, intensity). *Pipeline building has a learning curve; the image.sc forum is the official support channel.* | Direct download for Windows/macOS; also `pip install cellprofiler` for headless batch runs. | Free | 3/5 |
| [**ColabFold**](https://github.com/sokrypton/ColabFold) | Free AlphaFold2/ESMFold protein structure prediction accelerated by MMseqs2 sequence search; runs in Google Colab notebooks so a browser plus the free Colab GPU tier is enough to predict structures not already in AlphaFold DB. *Free Colab GPUs are time-limited and can disconnect on long/multimer jobs. The public MMseqs2 API asks heavy users (>1,000 predictions) to run their own server. Check current terms for commercial use of predictions.* | Open the AlphaFold2_mmseqs2 notebook linked from the GitHub README in Google Colab (free Google account), paste a sequence, run; LocalColabFold installs the same stack on your own machine. | Free, email | 4/5 |
| [**Fiji (ImageJ)**](https://fiji.sc/) | The de facto standard open-source scientific image analysis package: ImageJ bundled with hundreds of plugins for microscopy — segmentation, tracking, stitching, deconvolution — plus a macro language and Python scripting. *Very large images can exceed laptop RAM; the BigDataViewer ecosystem inside Fiji mitigates this.* | Direct download from fiji.sc (Windows/macOS/Linux, no install rights needed); runs on ordinary laptops. | Free | 5/5 |
| [**IGV (Integrative Genomics Viewer)**](https://igv.org/) | Free desktop and web viewer from UCSD/Broad for interactively inspecting BAM alignments, VCFs and annotation tracks against a reference genome — the standard way to eyeball a variant call before believing it. | Desktop download at igv.org; IGV-Web runs in the browser with no install; igv.js embeds the viewer in your own pages. | Free | 4/5 |
| [**NCBI BLAST**](https://blast.ncbi.nlm.nih.gov/) | The canonical sequence similarity search. The free web server searches your sequence against GenBank/RefSeq/PDB databases with no setup; the BLAST+ suite runs the same searches locally against custom databases. *Web BLAST throttles heavy automated use; for thousands of queries run BLAST+ locally or on Galaxy.* | Paste a sequence at blast.ncbi.nlm.nih.gov (no login); standalone via `conda install -c bioconda blast` then `makeblastdb` + `blastn`/`blastp`. | Free | 5/5 |
| [**Nextflow + nf-core**](https://nf-co.re/) | Nextflow is a free workflow engine that runs the same pipeline on a laptop, HPC cluster or cloud; nf-core is its community collection of curated, peer-reviewed, containerized pipelines (RNA-seq, variant calling, metagenomics, and dozens more). *Requires Java plus Docker/Singularity/conda. The commercial Seqera Platform is optional; the engine and all nf-core pipelines are fully open source.* | `curl -s https://get.nextflow.io \| bash`; then e.g. `nextflow run nf-core/rnaseq -profile test,docker`. All pipelines and containers are free. | Free | 2/5 |
| [**QIIME 2**](https://qiime2.org/) | The standard open-source platform for amplicon (16S/ITS) and increasingly shotgun microbiome analysis, with built-in provenance tracking so every result records exactly how it was produced. *Installation is the hardest step; the documented conda environments are the reliable route. The user forum is active and developer-staffed.* | Install via conda (distribution-specific environment files on the docs site) or Docker; extensive free tutorials; results viewable at view.qiime2.org. | Free | 2/5 |
| [**samtools / bcftools / htslib**](https://www.htslib.org/) | The core command-line stack for sequencing data: samtools for SAM/BAM/CRAM alignments, bcftools for VCF/BCF variant files, built on htslib. Effectively mandatory infrastructure for any genomics pipeline. *Command-line only; assumes comfort with a Unix shell (the Carpentries or sandbox.bio tutorials cover the prerequisites).* | `conda install -c bioconda samtools bcftools`; typical use `samtools sort in.bam -o sorted.bam`, `bcftools view calls.vcf.gz`. | Free | 2/5 |
| [**Snakemake**](https://snakemake.github.io/) | Python-based workflow management system widely used in bioinformatics for reproducible, scalable analyses; rules declare inputs/outputs and Snakemake resolves the execution graph, with conda/container integration. *Gentler learning curve than Nextflow for Python users; community workflow catalog exists but is less standardized than nf-core.* | `pip install snakemake` (or via conda); define a Snakefile and run `snakemake --cores 4`. | Free | 3/5 |

## Literature

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**bioRxiv**](https://www.biorxiv.org/) | The main preprint server for biology, founded at Cold Spring Harbor Laboratory in 2013 and operated since 2025 by the nonprofit openRxiv. Free to post and free to read, with basic screening (not peer review) and direct transfer to many journals. *Preprints are screened but not peer reviewed. Clinical/health-science work goes to sibling server medRxiv. Check journal policies before posting, though nearly all major life-science journals now allow preprints.* | Read freely on the web; submit via the web form with a free account; API at api.biorxiv.org for metadata; full-text corpus available for text mining. | Free, email | 5/5 |
| [**Europe PMC**](https://europepmc.org/) | EMBL-EBI's literature database layered over PubMed/PMC content: abstracts plus millions of free full-text articles and life-science preprints (including bioRxiv), with text-mined annotations linking papers to genes, proteins and chemicals. *The strongest legal route to programmatic full-text access in the life sciences; only the open-access subset allows bulk redistribution.* | Web search; REST API at ebi.ac.uk/europepmc/webservices/rest for search, full text and annotations; bulk open-access subset downloadable for mining. | Free | 4/5 |
| [**PubMed**](https://pubmed.ncbi.nlm.nih.gov/) | The free NLM index of more than 38 million biomedical and life-science citations and abstracts, with links to full text where available including free full text in PubMed Central. *Indexes abstracts, not full text — pair with PubMed Central/Europe PMC or Unpaywall-style tools for the papers themselves.* | Web search; programmatic access via E-utilities API; whole-baseline downloads for text mining; free My NCBI account adds saved searches and email alerts. | Free | 5/5 |

## Publishing

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**eLife**](https://elifesciences.org/) | Nonprofit open-access journal using a publish-review-curate model: every reviewed submission is published as a Reviewed Preprint with a public eLife Assessment and reviews, rather than receiving accept/reject decisions. All content is free to read. *The assessment-instead-of-accept/reject model is still viewed skeptically by some hiring committees; weigh field norms. Reading is entirely free; the fee applies only to authors who can pay.* | Submit direct or transfer from bioRxiv/medRxiv; the $3,750 fee is payable during peer review and is waived for anyone who cannot afford it, no questions beyond a request. | Free tier, email | 3/5 |
| [**microPublication Biology**](https://www.micropublication.org/) | Caltech-based journal publishing peer-reviewed single-result findings (including negative and reproduction results) that would not fill a full paper; articles are indexed in PubMed and deposited into the relevant model-organism databases. *Ideal for graduate students turning orphan results into citable, PubMed-indexed publications; scope is strongest in model-organism genetics.* | Submit a brief structured article via micropublication.org; APC is $350 (since January 2025), and no article is refused for inability to pay. | Free tier, email | 4/5 |
| [**Peer Community In / Peer Community Journal**](https://peercommunityjournal.org/) | PCI communities peer-review and recommend preprints for free; recommended articles can then publish in Peer Community Journal — diamond open access with no APC and no reader fees, backed by CNRS, INRAE and hundreds of institutions. Strongest coverage in ecology, evolution, genomics and related fields. *Review can be slower than at commercial journals, and name recognition varies by subfield — but it is a genuinely zero-cost, rigorous route from preprint to peer-reviewed article.* | Post your preprint (e.g. bioRxiv), submit it to the relevant PCI community (PCI Ecology, PCI Evolutionary Biology, etc.) for review; on recommendation, opt to publish in Peer Community Journal at no cost. | Free, email | 3/5 |
| [**PLOS**](https://plos.org/) | Nonprofit open-access publisher (PLOS ONE, PLOS Biology, PLOS Computational Biology, etc.). 2026 APCs range from about $1,088-$2,477 at PLOS ONE to $3,150-$6,460 at the selective journals, but two substantive fee-relief routes exist for unfunded authors. *PFA must be requested at submission, not after acceptance, and expects you to demonstrate need and exhaust institutional/funder sources first. All PLOS content is free to read (CC BY).* | Submit via each journal's site; apply for Publication Fee Assistance (PFA) at submission (decision ~10 business days); authors in Research4Life Group A countries get a complete waiver, Group B substantial reductions. | Free tier, email | 3/5 |
| [**protocols.io**](https://www.protocols.io/) | Platform for writing, versioning and publicly sharing step-by-step research protocols; public protocols get a DOI and a CC BY license at no cost to author or reader. Owned by Springer Nature since 2023 and now the successor to Protocol Exchange. *Public sharing is free; private team workspaces beyond a small scale are the paid product. Public protocols are not peer reviewed.* | Free account; author in the web editor; click publish to make a protocol public with a citable DOI. | Freemium, email | 5/5 |

## Funding

| [**Experiment.com**](https://experiment.com/) | All-or-nothing crowdfunding platform specifically for scientific research projects, with roughly a 48% campaign success rate; open to independent researchers and students, not just institutional labs. *Platform takes 8% plus ~3-5% payment processing from funded projects. | [**National Geographic Society Grants**](https://www.nationalgeographic.org/society/grants-and-investments/) | Funds individuals (18+) in science, conservation, storytelling and education; Level I grants provide up to $20,000 plus mentorship and entry to the Explorer community, and do not require a prior institutional grant record. *The Society has moved from open calls to time-bound, themed RFPs — check which RFPs are open before planning an application (a 2026 cycle deadline was April 12, 2026). | [**Rufford Small Grants**](https://www.rufford.org/) | Staged grants for nature conservation projects in non-developed countries, starting at £6,000 and rising to £15,000 across up to five successive grants; priority to current or recent (within 3 years) MSc/PhD students. *Only fieldwork costs in eligible (non-developed) countries are funded, the focal species must be threatened, and BSc students are not eligible. A realistic first grant for early-career conservationists in the Global South.* | Apply any time at apply.ruffordsmallgrants.org (no deadlines; one application per 12 months). | Free, application | 3/5 |

## Learning

| Resource | What it is | Access | Free | Beginner |
|---|---|---|---|---|
| [**EMBL-EBI Training**](https://www.ebi.ac.uk/training/) | Free on-demand courses and recorded webinars from EMBL-EBI covering its own resources (UniProt, Ensembl, PDBe, Europe PMC) and general methods — variant calling, networks, proteomics, bioimage analysis — written by the teams that run the databases. *Live virtual courses have limited seats and sometimes fees; the on-demand catalogue is entirely free.* | Browse ebi.ac.uk/training/on-demand and click Enter Course; no fee, no enrollment gate. | Free | 5/5 |
| [**Galaxy Training Network**](https://training.galaxyproject.org/) | Hundreds of free, hands-on tutorials (transcriptomics, variant analysis, single-cell, metagenomics, proteomics, ecology) designed to run on the free public Galaxy servers — so the compute for every exercise is also free. *Because everything runs in Galaxy, no local installation is needed — the most realistic full-workflow practice available without a cluster.* | Pick a tutorial at training.galaxyproject.org, follow it on usegalaxy.org/.eu with a free account; slides, videos and example histories included. | Free | 4/5 |
| [**iBiology**](https://www.ibiology.org/) | Free library of 600+ videos of leading biologists (including 25+ Nobel laureates) explaining their research and methods, plus free courses on microscopy, career skills and experimental design. Now part of the Science Communication Lab. *New production has shifted toward the Science Communication Lab's films, but the full back catalogue (including the well-known Microscopy Series) remains free.* | Stream free at ibiology.org and on YouTube; structured free courses at courses.ibiology.org. | Free | 5/5 |
| [**Rosalind**](https://rosalind.info/) | Free platform (UCSD and partners, running since 2012) that teaches bioinformatics through an auto-graded problem tree — from string algorithms on DNA to alignment, phylogenetics, combinatorics and mass spectrometry. Only an internet connection and a programming language are required. *Teaches algorithms, not tool usage — pair with the Carpentries or Galaxy Training for practical pipeline skills.* | Free account at rosalind.info; download each problem's dataset, compute the answer locally in any language, paste the result for instant grading. | Free, email | 5/5 |
| [**sandbox.bio**](https://sandbox.bio/) | Free interactive bioinformatics tutorials that run a real Linux terminal in your browser (tools compiled to WebAssembly): samtools, bedtools, bcftools, seqkit, IGV and more, preloaded with data — zero setup. *Covers tool fluency in short sessions; not a substitute for running real-sized datasets, but the fastest possible first contact with the standard toolstack.* | Open sandbox.bio in a browser and start a tutorial; everything executes client-side (needs >1 GB RAM). | Free | 5/5 |
| [**The Carpentries (Software & Data Carpentry)**](https://carpentries.org/) | Community-built, openly licensed (CC BY) lessons teaching shell, Git, Python, R and SQL for researchers, plus Data Carpentry curricula for genomics and ecology built around real datasets. The lessons the life-science community itself uses to train beginners. *The Genomics Carpentry curriculum is the standard on-ramp to the samtools/command-line stack for wet-lab biologists.* | All lessons free for self-study at software-carpentry.org and datacarpentry.org; live workshops run worldwide through host organizations. | Free | 5/5 |
